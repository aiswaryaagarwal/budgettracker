# 💰 Budget Tracker

A personal budget tracking web app built with Python and Flask.

## Features
- Add credit and debit transactions
- Add description and date to each transaction
- Edit existing transactions
- View all transactions
- Real-time balance calculation
- Data saved locally using JSON

## Tech Stack
- Python
- Flask
- HTML & CSS
- JSON for data storage

## How to Run

### 🌐 Web App (Flask)
1. Install Requirements: `pip3 install -r requirements.txt`
2. Run the app: `python3 budgettrackerapp.py`
3. Open browser: `http://localhost:5000`

### 💻 CLI Version (Terminal only)
1. Run directly — no installation needed!
   `python3 budgettracker.py`
